     Wave 0 — TUI Integrity Sweep: Implementation Plan

     Context

     VAC's TUI has grown feature-rich but accumulated significant integrity
     debt:
     - 3 key binding collisions (Ctrl+E, Ctrl+X, Ctrl+V) where later arms are
     unreachable
     - 7 dead key bindings mapped to InputEvent variants with no handler
     - 10+ incorrect entries in the shortcuts popup (wrong key descriptions)
     - 11 phantom slash commands listed in shortcuts popup that don't exist in
     vac_commands()
     - 6 passthrough commands labeled BuiltIn that silently forward to the LLM
     - Dispatch duplication between main input and command palette (8 commands
     missing from palette)
     - Zero test coverage for slash command dispatch, keymap uniqueness, or
     event handler coverage

     Wave 0 closes this debt so Wave 1+ can build on a trustworthy foundation.
